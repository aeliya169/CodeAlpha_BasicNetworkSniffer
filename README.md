# CodeAlpha Basic Network Sniffer

## Description

A basic network sniffer developed in Python using Scapy.  
This project captures network packets and displays basic information about network communication.

## Features

- Captures network packets
- Displays source IP address
- Displays destination IP address
- Identifies network protocols
- Displays source and destination ports

## Technologies Used

- Python
- Scapy
- Npcap

## How to Run

1. Install Python.
2. Install Scapy using:
   `pip install scapy`
3. Run the program:
   `python network_sniffer.py`
